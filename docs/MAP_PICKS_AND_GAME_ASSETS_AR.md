# صور الخرائط واقتراحات البراولرز

تاريخ التحقق: 18 سبتمبر 2026.

## المصادر

| الاستخدام | المصدر | نتيجة التحقق |
| --- | --- | --- |
| الخرائط الحالية ووقت نهايتها | API الرسمي عبر `/events/rotation` الموجود | يبقى مصدر دوران الخرائط |
| صور الخرائط وأيقونات الأطوار والبراولرز | [BrawlAPI / Brawlify](https://brawlapi.com/#maps) | كتالوج مجاني بلا مفتاح؛ تُطابق الصور بمعرّف الخريطة والطور |
| اقتراحات البراولرز ونسب المصدر | [BrawlTools API](https://api.brawltools.net/docs) | API موثّق مجاني بلا تسجيل، مع حدود طلبات وطلب نسب المصدر إليه؛ `/maps` يعيد القائمة في طلب واحد |

كتالوج BrawlAPI الحالي ثابت: حقلا `stats` و`teamStats` فارغان. لا تُشتق منه نسب فوز. يوفر BrawlTools إحصاءات يجمعها عبر API اللعبة الرسمي بحسب [وصفه](https://api.brawltools.net/openapi.json)، ويذكر تخزينًا مؤقتًا يقارب 120 ثانية. لا حاجة إلى شراء خدمة أو إنشاء مفتاح جديد. لا ندّعي حصة غير محدودة أو ضمان استمرار المصدر.

فُحص أيضًا Brawl Time Ninja، لكن مسار رمز الاتصال المجهول أعاد 403 من Vercel رغم نجاحه محليًا. لذلك لا تعتمد النسخة المنشورة عليه ولا تستخدم وسيطًا لتجاوز الرفض.

## تفسير الأرقام

- تعرض الواجهة قائمة `winRateHigh` الأعلى لدى المصدر، مرتبة حسب النسبة التي ينشرها. لا تُقدّم بوصفها ترتيبًا مضمونًا للمحترفين أو فرصة فوز شخصية.
- وثائق أوامر BrawlTools تذكر 800 كأس في سياق الأحداث وLegendary I في سياق الخرائط/Ranked، بينما لا يحدد مخطط API تفسير `High/Low`. لذلك لا نسمي الفئة 1000+ أو 800+ ولا ننشئ فلتر كؤوس يدّعي عتبة غير مثبتة.
- المصدر لا يوفر عدد النتائج لكل براولر ولا معدل استخدامه. تبقى هذه القيم غير متاحة، ولا يُستبدل بها إجمالي مباريات الخريطة أو `popularity`.
- `totalMatches` إجمالي الخريطة كما ينشره المصدر، وليس عدد مباريات كل براولر أو عدد مباريات الفئة المختارة. يظهر منفصلًا في التفاصيل.
- لا توجد فترة إحصائية موثقة في الاستجابة؛ لا نسميها آخر سبعة أيام أو موسم Ranked.
- `timestamp` وقت لقطة المصدر، وليس تاريخ آخر مباراة مؤكدة. يُعرض منفصلًا عن وقت جلب التطبيق.
- لا يشرح المصدر معادلة الفوز في Showdown. تُعرض اقتراحاته بالترتيب دون نسبة مئوية، ولا تُنسب الأرقام إلى المركز الأول أو الفوز ضمن النصف الأعلى.
- البيانات المفقودة لا تتحول إلى صفر. تُرفض النسب خارج 0–100، وتبقى نسبة الصفر الصحيحة صفرًا.

تُطابق الإحصاءات بمعرّف الخريطة وبيانات طورها، مع فصل Solo وDuo وTrio. يُرفض تعارض الطور أو الاسم. عند غياب وصف الطور لدى المصدر يمكن التحقق من معرّف الخريطة واسمها عبر الكتالوج ودوران اللعبة الرسمي؛ لا تكفي مطابقة الاسم وحده.

## الواجهة

أيقونات الأطوار من صور اللعبة في Brawlify، وأيقونات التنقل والإجراءات من SVG. لا تُستخدم رموز تعبيرية يؤلفها التطبيق. أسماء اللاعبين والنادي ووصفه تبقى كما ترد من اللعبة.

تظهر صورة الخريطة كاملة دون قص، ويمكن تكبيرها. تعرض البطاقة ثلاثة براولرز بصورهم وإطاراتهم الأصلية ونسب المصدر عندما تكون دلالتها مناسبة للطور، مع إمكان عرض عشرة. المصدر وحدود الأرقام والتوقيت داخل تفاصيل قابلة للفتح.

تعذّر صورة أو مصدر الإحصاءات لا يخفي دوران الخرائط الرسمي. للصور بديل SVG، وتُعلّم النتائج المتأخرة أو غير المتاحة بوضوح. تبقى شارة النادي مطابقة لمعرّفها المسجّل.

يسمح [توثيق CDN لدى Brawlify](https://github.com/Brawlify/CDN) بربط الصور مباشرة. يظهر إشعار موجز واحد في أسفل التطبيق وفق [سياسة محتوى المعجبين لدى Supercell](https://supercell.com/en/fan-content-policy/) يوضح أن التطبيق غير رسمي وغير معتمد منها.

## تقليل الطلبات والتحقق

تُجلب قائمة صور واحدة وقائمة BrawlTools مجمّعة واحدة. تُحفظ نسخة مختصرة من الاستجابات الناجحة ساعةً في ذاكرة Next المشتركة؛ وتُعاد للمتصفح الخرائط الحالية فقط. فشل التحديث يحافظ على النسخة الناجحة السابقة مع توقيتها. يوجد دمج للطلبات المتزامنة وتأخير خمس دقائق للمحاولات الفاشلة داخل عامل الخادم؛ هذا التأخير ليس قفلًا موزعًا بين كل الخوادم.

المسار يقبل فئة مصدر محددة فقط، دون روابط أو استعلامات حرة. طلبات المصدر محدودة الوقت والحجم، وإعادة التوجيه ممنوعة. زر التحديث لا يتجاوز تخزين المصدر. تسجَّل معلومات فشل محدودة دون محتوى الاستجابات أو أسرار. فحص النشر يتأكد من وصول صور الخرائط واقتراحات البراولرز فعليًا، إضافة إلى فحوصات الصفحات والخصوصية.
