# صور الخرائط واقتراحات البراولرز

تاريخ التحقق: 18 سبتمبر 2026.

## المصادر

| الاستخدام | المصدر | نتيجة التحقق |
| --- | --- | --- |
| الخرائط الحالية ووقت نهايتها | API الرسمي عبر المسار الموجود `/events/rotation` | يبقى مصدر دوران الخرائط؛ لا نستبدله بجدول مجتمعي |
| صور الخرائط وأيقونات الأطوار والبراولرز | [BrawlAPI / Brawlify](https://brawlapi.com/#maps) | كتالوج مجاني بلا مفتاح، مع توصية التخزين ساعة. مسار الخرائط `https://api.brawlapi.com/v1/maps` يعيد الصور والمعرّفات |
| نتائج البراولرز لكل خريطة | [Brawl Time Ninja](https://brawltime.ninja/tier-list/mode/gem-grab/map/Hard-Rock-Mine) | نتائج فعلية مع حجم العينة، معدلات المصدر، ومعرّف الخريطة وتوقيت آخر رصد |

كتالوج BrawlAPI الحالي ثابت: حقلا `stats` و`teamStats` فارغان، وقائمة الأحداث لا توفر دورانًا حيًا. لذلك لا تُشتق منه نسب فوز أو توصيات مختلقة. لا حاجة إلى شراء خدمة أو إنشاء مفتاح جديد للمصدرين المستخدمين. لم يُعثر على تعهّد باستمرار API الإحصاءات أو حصة طلبات غير محدودة.

## تفسير الأرقام

- مطابقة الصور بمعرّف الخريطة والطور معًا. Solo وDuo وTrio تبقى منفصلة. يجمع Ninja الإحصاءات باسم الخريطة والطور، ويعرض معرّفًا تجميعيًا؛ قد يدمج مراجعات تحمل الاسم نفسه. نتحقق من تطابق المعرّفات المتاحة، ونرفض إحصاءات الخريطة إذا ظهر تعارض بدل حذف بعض البراولرز وتضخيم معدلات البقية. لا ندّعي أن هذا يثبت فصل كل نسخة تاريخية.
- حجم العينة عدد نتائج اللاعبين التي رصدها Ninja، وليس عدد مباريات فريدة ولا جميع مباريات اللعبة.
- معدل الاستخدام هو نتائج البراولر مقسومة على نتائج **جميع** براولرز الخريطة والطور، قبل اختيار أعلى النتائج. لا يُحسب من الثلاثة المعروضين فقط.
- نسبة الأطوار العادية تستخدم معادلة المصدر، التي تمنح التعادل جزءًا من نقاط الفوز. لا نحولها إلى عدد انتصارات صحيح مفترض.
- مؤشر `winRate` الأصلي في Showdown هو درجة ترتيب مطبّعة؛ ليس نسبة الفوز. الواجهة تستخدم `rank1Rate_measure` وتسمّيه **نسبة المركز الأول**.
- البداية بخيارات الأكثر استخدامًا عند **1000 كأس فأكثر للبراولر المستخدم**، مع إمكان اختيار 600+ أو كل المستويات. هذا ليس مجموع كؤوس الحساب ولا تصنيف Ranked، ولا تتراجع النتائج تلقائيًا إلى مستويات أقل عند نقص العينة.
- ترتيب نسب الفوز يتطلب 500 نتيجة على الأقل لكل براولر، وترتيب الاستخدام يتطلب 100؛ العينة مجهولة الحجم تُستبعد. يبقى معدل الاستخدام محسوبًا من جميع النتائج قبل تطبيق حدود العرض.
- بيانات Ninja مأخوذة من زواره؛ لا نسمّيها ترتيبًا مضمونًا للاعبين المحترفين أو لكل اللاعبين. الفلتر يقلل أثر مباريات الكؤوس المنخفضة؛ لا يثبت المهارة وحده.
- فترة المصدر حاوية من 14 يومًا، وليست موسم Ranked أو آخر سبعة أيام. الفترة وقت التحقق: 14–28 سبتمبر 2026، 08:00 UTC. يعرض التطبيق فترة المصدر ووقت آخر نتيجة بصورة منفصلة عن وقت جلبها.
- القيمة المفقودة تبقى غير متاحة؛ لا تتحول إلى صفر. اسم براولر جديد لا يُستبدل بصورة براولر آخر.

## الواجهة

أيقونات الأطوار تأتي من صور اللعبة في Brawlify، وأيقونات التنقل والإجراءات من SVG. لا تُستخدم رموز تعبيرية يؤلفها التطبيق. أسماء اللاعبين والنادي ووصفه تبقى كما ترد من اللعبة.

تظهر صورة الخريطة كاملة دون قص، ويمكن تكبيرها. تعرض البطاقة ثلاثة خيارات افتراضيًا، مع الصورة ونسبة الفوز/المركز الأول ومعدل الاستخدام وحجم العينة؛ ويمكن عرض المزيد. تفاصيل الحساب والمصدر داخل قسم قابل للفتح.

تعذّر صورة أو مصدر إحصاءات لا يخفي دوران الخرائط الرسمي. الصور لها بديل SVG، والنتائج غير المتاحة أو المتأخرة تُعلّم بوضوح.

تستخدم صور البراولرز الجديدة الإطارات الأصلية في مسار `brawlers/borders`، وتظهر شارة النادي المسجّلة بمعرّفها الحقيقي. يسمح [توثيق CDN لدى Brawlify](https://github.com/Brawlify/CDN) بربط الصور مباشرة. أُضيف إشعار موجز واحد في أسفل التطبيق تفرضه [سياسة محتوى المعجبين لدى Supercell](https://supercell.com/en/fan-content-policy/) لتوضيح أن التطبيق غير رسمي وغير معتمد منها.

## تقليل طلبات المصادر

تُجلب قائمة صور واحدة ودفعة إحصاءات واحدة للخرائط الحالية، وتُعاد للمتصفح الخرائط الحالية فقط. تُخزَّن الاستجابات الناجحة ساعةً في ذاكرة Next المشتركة؛ وفشل تحديث نتيجة محفوظة يُبقي النتيجة القديمة مع توقيتها. يوجد أيضًا دمج للطلبات المتزامنة وتأخير خمس دقائق للمحاولات الفاشلة داخل عامل الخادم، وتخزين لاستجابة المسار عند الحافة لمدة دقيقة. تأخير الفشل ليس قفلًا موزعًا بين كل الخوادم، ولا ندّعي طلبًا واحدًا عالميًا أثناء بدء خوادم باردة متعددة.

لا تُرسل مفاتيح Brawl Stars إلى Ninja، ولا يصل رمز الدخول المجهول المؤقت للمصدر إلى المتصفح. لا يقبل المسار وجهات أو روابط أو استعلامات يحددها الزائر؛ لها حدود وقت وحجم وإعادة توجيه مقفلة. زر التحديث لا يتجاوز وتيرة تخزين المصادر.

يُطابق الاتصال بروتوكول Cube المستخدم لدى Ninja: تتحول الاستعلامات الطويلة إلى POST، وتُعاد محاولة استجابة `Continue wait` بعد انتظار قصير ضمن مهلة إجمالية محدودة. يسجّل الخادم مرحلة الفشل ورمز HTTP فقط، دون رموز الدخول أو محتوى الطلب. يشمل فحص النشر وصول صور الخرائط وإحصاءات البراولرز فعليًا، وليس نجاح تحميل الصفحة فقط.
