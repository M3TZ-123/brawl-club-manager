**تحسين مصادر البيانات والأداء — سبتمبر 2026**

تُقرأ نقاط ورتب Ranked من استجابة اللاعب المستخدمة أصلًا في المزامنة الكاملة. يستدعي التطبيق RNT فقط لإكمال حقول غير متاحة، وبفاصل محفوظ لكل لاعب يشمل التحديث اليدوي. الرتبة الحالية وأفضل رتبة موسمية وأفضل رتبة تاريخية حقول منفصلة؛ تعذّر القراءة لا يمسح القيمة المعروفة، والرتبة غير المعروفة لا تُعرض Unranked.

يحفظ التطبيق النقاط والموسم ومصدر القراءة ووقتها. يُعرض وقت آخر فحص كامل للرتبة في ملف اللاعب. توقيت القراءة يعني وصول البيانات إلى التطبيق، ولا يضمن زمن تحديث مزوّدها الداخلي. أصبحت وتيرة Ranked العادية مرتبطة بالملفات، عشر دقائق افتراضيًا؛ الثلاثون دقيقة تخص المصدر الاحتياطي فقط.

طلب Dashboard يستخدم RPC واحدة بدل عشرة اتصالات بقاعدة البيانات. ترتيب النشاط يجمع الفترة المختارة داخل SQL ويحذف الحسابات والحقول غير المعروضة. تبقى الردود العامة صريحة الحقول وغير مخزّنة مؤقتًا على الخادم، وتظل الملاحظات الخاصة خارجها.

تشارك مكونات الواجهة حالة جلسة الإدارة وطلب التحقق. تُلغى الطلبات القديمة عند تغير الجلسة، وتُدمج إشارات التحديث أثناء الطلب الجاري. جلب البيانات له مهلة تشمل جسم الاستجابة. يقرأ سجل المعارك أسماء الأعضاء من رده نفسه، ويستخدم فهرس صور صغيرًا مضمّنًا بدل تحميل كتالوج Brawlify الكامل. للصور غير المتاحة بديل محلي.

تُرسل `club_sync_signals` إشارة صغيرة واحدة عند نجاح الحفظ في نفس المعاملة، بدل الاشتراك في كل معركة جديدة. لا تظهر إشارة لمحاولة فاشلة أو متراجعة. ينقطع اشتراك التبويب المخفي ويعود مع فحص الحالة عند ظهوره. يستمر فحص الحالة كل ثلاثين ثانية لاستدراك الرسائل الفائتة.

تعمل وظائف Vercel في `dub1` قرب قاعدة Supabase الموجودة في `eu-west-1` بأيرلندا. لا يتطلب هذا إضافة مدفوعة أو نقل قاعدة البيانات. يستمر استخدام RoyaleAPI لتوافق عنوان الخروج مع مفتاح اللعبة المقيد بعناوين IP.

تُحفظ مرحلة الفشل وحالة HTTP أو SQLSTATE بصيغة محدودة في سجل التشغيل الخاص، دون أجسام استجابات أو مفاتيح. بقيت الرسائل العامة آمنة ومختصرة.

ترتيب ترحيلات قاعدة البيانات: `015_ranked_profile` ثم `016_sync_signals` ثم `017_reporting_reads` ثم `018_api_backups`. الترقيات إضافية وتحافظ على توافق مسار المزامنة السابق أثناء النشر. تشمل النسخة الاحتياطية جدول انتظار RNT وإشارة التحديث والصلاحيات والوظائف الجديدة؛ اختبار الاستعادة يتحقق منها داخل قاعدة محلية فارغة.
